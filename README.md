# 人生確変ツール

本や考え方を「実践する」ためのツールを集めるフォルダ。1つのツールにつき1つのフォルダを作る。

## ツール一覧

| フォルダ | 中身 | 開き方 |
|---|---|---|
| [ザ・マジック](ザ・マジック/) | ロンダ・バーン『ザ・マジック』の28日間の感謝の実践 | `ザ・マジック/index.html` をダブルクリック |
| [こうして、思考は現実になる](こうして、思考は現実になる/) | パム・グラウト『こうして、思考は現実になる』の9つの実験ノート（本人用） | 公開ページから開く |
| [成功の証ノート](成功の証ノート/) | ほしい物（成功の証）のボード、お金の道のり、ブログの記事と収益の記録、毎週のWOOP（本人用） | 公開ページから開く |

`index.html`（このフォルダ直下）は、ツール一覧の入口ページ。

## 新しいツールを足すとき

1. このフォルダの中に、ツールの名前でフォルダを作る
2. その中に `index.html`（ツール本体）と `README.md`（使い方）を置く
3. 上の表と、入口ページ `index.html` に1つずつ足す
4. GitHub にあげ直す（下の「直したあと」）

## 直したあと

このフォルダで次を打つと、1〜2分で公開ページに反映される。URLは変わらず、使う人の記録も消えない。

```bash
git add -A && git commit -m "直した内容" && git push
```

あげ直す前に、直したページの中の `const VERSION = '…'` を新しい値に変える（例：`2026-10-30.1`）。こうしておくと、スマホに古いページが残っていても、開いた時に自動で新しい版に読み直される。入口の `index.html` も同じ。

それでも古いままに見える時は、ページを開き直す（下に引っぱって更新）。
