# 自分像ノート

「自分はこういう人間だ」という自分像（自己認識）を、毎日の言葉・証拠・イメージで書きかえていくノート。本人用。

言葉だけでは自分像は変わりにくく、「もうそういう人」として動いた証拠がたまった時に変わる。そこで、朝・昼・夜の3つを毎日まわす。

## 開き方

https://tumugi-create.github.io/jinsei-kakuhen-tools/%E8%87%AA%E5%88%86%E5%83%8F%E3%83%8E%E3%83%BC%E3%83%88/ を開く（入口ページからも開ける）。PCでもスマホでも使える。記録は開いた機械のブラウザの中に保存される。

## 画面

| タブ | 中身 |
|---|---|
| 今日 | **朝**：言葉を1つずつ大きく出して言う（言ったら気分を5秒味わう。PCは Enter キーで次へ）。**昼**：「もうそういう人」の証拠を、お金・仕事／見た目／人／自分に分けて書き留める（1つ＝自分への1票、1日3つが目安）。**夜**：寝る前に思い浮かべる、叶った後の1場面 |
| 言葉 | 朝の言葉を直す・並べかえる・足す。寝る前の場面を書く |
| 記録 | 続いた日数、いちばん長く続いた日数、自分への票の合計。この4週間の色分け（朝・昼・夜のうち、できた数）。分野ごとの票。証拠の一覧 |
| 設定 | 文字の大きさ、画面の色、バックアップ、やり直し |

## 最初から入っている言葉

2026-11-04 に本人と決めた8つ。どれも「もう叶っている」形（完了形）で書いている。言葉を足したり直したりする時も、この形にそろえる。

1. 俺は月1000万を稼ぐ考え方と力を、もう持ってる
2. 俺がやったことは、お金と信頼と結果になって、ちゃんと返ってくる
3. 俺の顔つきは自信がにじみ出てて、どんどん引き締まってる
4. 俺は、黒のヴィトンを自然に着こなす男や
5. 俺といると、家族も恋人も仲間も笑顔になる
6. 俺の周りには、一緒にいて心地いい人ばっかり集まってる
7. やれば誰でもできるのに、もったいないなぁ。俺はもうやってる側やもんな
8. 俺の人生は、毎日MAXを更新してる

## 数字の出し方

- **続いた日数**：朝・昼・夜のどれか1つでもした日が、今日（まだなら昨日）から何日続いたか
- **朝ができた**：その日に、言葉をぜんぶ言った
- **昼ができた**：その日に、証拠を3つ以上書いた
- **夜ができた**：その日に「思い浮かべた」を押した
- **自分への票**：これまでに書いた証拠の数

保存キーは `jibunzou.v1`。
