# こうして、思考は現実になる　9つの実験ノート

パム・グラウト『こうして、思考は現実になる』（E-Squared）にある9つの実験を、実験ノートに書きながら進めるツール。本人用。

## 開き方

https://tumugi-create.github.io/jinsei-kakuhen-tools/こうして、思考は現実になる/ を開く（入口ページからも開ける）。PCでもスマホでも使える。記録は開いた機械のブラウザの中に保存される。

## 実験の流れ

1. 「実験」の画面で、仮説（セオリー・質問・仮説）とやり方を読む
2. 宣言を書く（書かずにはじめると、例の宣言が入る）
3. 「実験をはじめる」を押す。ここから期限（多くは48時間）のカウントダウンが始まる
4. 起きたこと・気づいたことを「観察ノート」に書き留める（時刻は自動）。実験によって、数を数えるボタンや毎日の記録欄がある
5. 期限が来たら（または結果がはっきりしたら）、「起きた！／少し起きた／起きなかった」を選び、気づきを書いて「実験を終える」

## 9つの実験

| 番号 | 法則 | 期間 | やること |
|---|---|---|---|
| 1 | 宇宙のエネルギーの法則 | 48時間 | 見えない力に、存在の証拠となる贈りものを頼む |
| 2 | フォルクスワーゲン・ジェッタの法則 | 48時間 | 24時間は黄色い車、次の24時間は黄色い蝶（紫の羽根）を探して数える |
| 3 | アインシュタインの法則 | 2時間 | 針金ハンガーのダウジングロッドで、考えによって針の向きが変わるか見る |
| 4 | アブラカタブラの法則 | 48時間 | ほしいものを細かく決めて、届くかを見る |
| 5 | 人生相談の法則 | 48時間 | 迷っている質問を1つ投げて、答えが届くかを見る |
| 6 | ハートブレイク・ホテルの法則 | 1週間 | 卵パックでインゲン豆を育て、念じた側が早く育つかを見る |
| 7 | 魔法のダイエットの法則 | 3日間 | 食べものを祝福し、体重が変わるかを見る |
| 8 | 101匹わんちゃんの法則 | 48時間 | 離れた人に心でメッセージを送り、反応があるかを見る |
| 9 | 魚とパンの法則 | 48時間 | 世の中のいいこと・美しいものを探して数える |

順番は決まっていないが、1から順にやるのがおすすめ。同じ実験を何度やってもよい（今のツールは1回分の記録）。

## 画面

| タブ | 中身 |
|---|---|
| 実験 | 今の実験。期限までの残り時間が輪で出る |
| 9つの実験 | 一覧と、それぞれの状態（まだ・実験中・結果） |
| レポート | はじめた実験を、実験レポートの形で読める。印刷・PDFにもできる |
| 設定 | 文字の大きさ、画面の色、バックアップ、やり直し |

## 注意

各実験の内容は、Web の要約や実践記録を見比べてまとめたもの（くわしくは [本との照合.md](本との照合.md)）。本そのものとは比べていない。実験3の所要時間、実験6の念じる側や種の数、実験7の目標などは資料によってちがった。結果は人によってちがい、効果を約束するものではない。
