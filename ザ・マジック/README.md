# ザ・マジック 28日間の感謝の実践

ロンダ・バーン『ザ・マジック』の28日間のワークを、毎日書きこみながら進めるツール。
スマホ（母）とPC（自分）の両方で使えるように作ってある。記録は機械ごとに別々に保存されるので、2人の記録が混ざることはない。

## 開き方

- **PC**：`index.html` をダブルクリックすると、ブラウザで開く
- **スマホ**：https://tumugi-create.github.io/jinsei-kakuhen-tools/ザ・マジック/ を開く。開いたら「設定」→「スマホのホーム画面に置く」の手順でホーム画面に置くと、アプリのように使える

## 毎日の流れ

「今日」の画面に、今日やることが3つの大きなボタンで並ぶ。押すとその作業だけの画面になり、終わったら「できた！ 今日のページに戻る」で戻る。

| ボタン | 中身 |
|---|---|
| 朝の感謝 | ありがたいことを10個と理由を書き、1つずつ「ありがとう」を3回押す（全28日） |
| 今日の実践 | 日ごとにちがうワーク（28種類）。やり方の説明つき |
| 夜の魔法の石 | 今日いちばんよかったことを書いて「ありがとう」（2日目から） |

最後に「今日の分を終える」を押すと、お祝いの画面が出て次の日へ進む。29日目以降も、朝と夜は続けられる。

## 見た目

紫からピンク、桃色へ変わる色づかいで、開くのが楽しみになる見た目。
背景は、ラベンダー・ピンク・桃色がふんわり混ざった色に、うすいハートと星の模様。

- 字体：見出しと数字は丸くてやわらかい「キウイ丸」、本文は読みやすい丸ゴシック「M PLUS Rounded 1c」
- アイコンは絵文字を使わず、線で描いた絵（朝＝太陽、実践＝きらめき、夜＝月）
- 今日の進み具合が輪で出る（0%→100%）。連続日数・達成日数・これまでの「ありがとう」の数も出る
- 「ありがとう」を3回押しきると、ボタンが色づいて、星やハートが舞い、「すてき！」などの声かけが出る（スマホでは軽くふるえる）
- 1日を終えると、紙吹雪とリボン付きのバッジでお祝い。7・14・21・28日目はバッジの色が変わる
- 「28日」の表では、済んだ日が色づき、今の日が光る

## 母親向けにしたところ

- 文字は大きめ（スマホは最初から「大きい」）。「設定」で ふつう／大きい／とても大きい に切りかえられる
- ボタンは指で押しやすい大きさ。スマホではタブが画面の下にある（PCでは上）
- 1画面に1つの作業だけ出すので、迷いにくい
- スマホでは「キーボードのマイクで話すだけで書ける」という案内が出る
- 英語の表記と絵文字をなくした

## 記録について

- 記録は、その機械のそのブラウザの中にだけ保存される
- ブラウザの閲覧データを消すと記録も消えるので、ときどき「設定」→「バックアップ」→「ファイルに書き出す」でバックアップを取る
- iPhone の Safari は、しばらく開かないサイトの記録を消すことがある。ホーム画面に置いておくと消えにくい

## 注意

各日の内容は、本の要点を自分の言葉で短くまとめたもの。数（10個・3人など）やくわしいやり方は、本で確かめて合わせてよい。
