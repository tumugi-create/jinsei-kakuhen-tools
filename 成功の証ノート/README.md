# 成功の証ノート

ほしい物（成功の証）を目に見える形で並べ、そこへ向かうブログの積み上げを毎日記録するノート。本人用。

## 開き方

https://tumugi-create.github.io/jinsei-kakuhen-tools/成功の証ノート/ を開く（入口ページからも開ける）。PCでもスマホでも使える。記録は開いた機械のブラウザの中に保存される。

## 画面

| タブ | 中身 |
|---|---|
| 今日 | 記事を書いたら題名と日付を入れて「書いた！」。記事の数・続いた日数・月100万円まであと何記事か。次の成功の証と「手に入って、ありがとう」。今日の行動のチェック。今週のWOOPの「壁が出たら → こうする」 |
| ブログ | 月末にアフィリエイト収益を記録 → 1記事あたりの収益（1か月）、月100万円に必要な記事の数、あと何記事、期限まで1日何記事のペースか。月ごとの記録と、記事の一覧（題名を押すと直せる） |
| 成功の証 | 財布 → 服 → ロレックス → クラウン／レクサスのカード（写真・モデル名・値段・手に入れる日・手に入れた日の場面）。先に感謝するボタン。手に入れたら実物の写真と日付を残してお祝い。お金の道のり。ザ・マジックの願いリストからカードを足せる |
| WOOP | 毎週の願い（Wish）・叶った姿（Outcome）・壁（Obstacle）・壁が出た時の行動（Plan）。前の週のものも読める |
| 設定 | 目標の月の収益（はじめは100万円）と期限（はじめは使いはじめた日の1年後）、文字の大きさ、画面の色、バックアップ、やり直し |

## 数字の出し方

- **続いた日数**：今日（まだ書いていなければ昨日）からさかのぼって、毎日1本以上書いた日が何日続いたか
- **1記事あたりの収益**：いちばん新しく記録した月の収益 ÷ その月末までに書いた記事の数
- **必要な記事**：目標の月の収益 ÷ 1記事あたりの収益。そこから今の記事の数を引いたものが「あと何記事」
- **1日何記事のペース**：あと何記事 ÷ 期限までの日数
- **お金の道のり（月にいくら必要か）**：まだ手に入れていない物を日付の早い順に並べ、「その日までの合計 ÷ その日までの月数」がいちばん大きいもの。日付のないカードは期限で計算し、1か月より近い日付は1か月として計算する。税金や生活費は入っていない

## ザ・マジックとのつながり

ザ・マジックで書いた願いのリスト（同じスマホ・同じブラウザに保存されているもの）が、「成功の証」タブの下と、WOOPの願いの候補に出る。

## 注意

目標と記録を見える化するためのノートで、お金の使い方・ローン・投資についての助言はしない。数字はざっくりの目安。YouTube の数字は記録しない（ブログに集中する）。
